# OADE-NSGA-II: current evidence

The previous integrated results narrative has been removed because it used comparator implementations preceding the corrections. The manuscript must now be developed from the [audited ZDT v2 results](../reports/zdt_seven_fixed_oade_v2_report.md), the sole starting point for current algorithm comparisons.

The current study includes fixed OADE and six corrected/library baselines on ZDT1/2/3/4/6. Its complete data, statistical results and limitations are recorded in the linked report. DTLZ/WFG have not been reevaluated with these implementations. A new publication-ready manuscript has not yet been drafted.
